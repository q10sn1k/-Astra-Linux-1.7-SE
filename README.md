# Расширенное администрирование Astra Linux SE 1.7

Учебные материалы по расширенному администрированию ОС Astra Linux Special Edition 1.7: загрузка и системные службы, управление программным обеспечением, хранение данных, журналирование, настройка сети, диагностика и автоматизация административных задач.

## Модуль 1

Загрузка системы, управление устройствами и программным обеспечением.

В каталоге [Mod 1/AI](Mod%201/AI/) размещены дополнительные материалы по работе с ИИ-ассистентами: ссылка на Qwen, вводная инструкция, препромпты и пример запроса для создания ассистента.

В каталоге [Mod 1/Network](Mod%201/Network/) размещены дополнительные материалы по сетевому взаимодействию и работе с API на Python.

## Подключение к учебной Astra Linux по SSH

[ssh_connection_guide.md](Mod%201/ssh_connection_guide.md) — пошаговая инструкция подключения к Astra Linux SE 1.7 из Arch Linux (fish и Bash), Debian, Ubuntu и Windows (PowerShell и PuTTY). Установка клиента, проверка ключа сервера, первые команды на ВМ, выход из сеанса, диагностика сети и VPN, поиск и завершение зависших SSH-процессов. Каждая команда сопровождается условным примером вывода и пояснениями ко всем параметрам и флагам. Реальные адреса, логины, пароли и ключи не используются.

## Практика: загрузка, systemd и управление пакетами

[astra_systemd_packages_practice.md](Mod%201/astra_systemd_packages_practice.md) — подробная практика для удалённой Astra Linux SE 1.7 после входа по SSH: стадии загрузки, службы systemd, journalctl, диагностика отказов и drop-in, таймеры, mount-юнит с ограниченным tmpfs, безопасное исследование модулей ядра, репозитории APT, симуляция системного обновления и полный цикл работы с собственным локальным пакетом. Каждая команда сопровождается примером результата и объяснением параметров. Упражнения используют отдельные учебные объекты; предусмотрены их очистка и проверка состояния системы.

## Практика point_1: локальный APT-репозиторий и обновление без Интернета

[point_1.md](Mod%201/point_1.md) — подробный материал для новичков в двух явно разделённых частях, целиком на одной удалённой Astra Linux SE 1.7 по SSH. Часть 1: пакеты, dpkg и APT, зависимости, проверка инструментов, установка недостающего генератора индекса, устройство и подключение репозиториев. Часть 2: пошаговое решение с собственными текстовыми пакетами; роли шлюза и целевого сервера моделируются каталогами этой же машины. Подготовка обновления и зависимости, получение через APT, перенос между каталогами с SHA-256, локальный репозиторий, отдельный sources.list.d, симуляция, установка и проверка. Для команд объяснены смысл, параметры и ожидаемые результаты; предусмотрены чек-лист, подтверждение выполнения и очистка.

## Препромпт «АстраКонтур» для администратора Astra Linux SE 1.7

[astrakontur_astra_linux_se_1_7_system_administrator_preprompt_v1_1_final.md](Mod%201/astrakontur_astra_linux_se_1_7_system_administrator_preprompt_v1_1_final.md) — системный препромпт специализированного ИИ-ассистента по защищённой эксплуатации Astra Linux SE 1.7. Помогает разбирать журналы и конфигурации, диагностировать загрузку и службы, планировать обновления, работать с сетью и хранилищами, готовить сценарии Bash и инструкции восстановления. Задаёт порядок работы: сбор фактов о конкретной системе, обоснование решения, минимальное изменение, независимая проверка результата, документирование и контролируемый откат.

Для использования добавьте файл в инструкции ИИ-ассистента или в материалы проекта и укажите задачу, выпуск системы и доступные результаты диагностики. Препромпт учитывает особенности Astra Linux SE и не даёт сам по себе разрешения на изменение реальной системы.

## Как использовать

1. Выберите файл под свою задачу и изучите его содержание.
2. Добавьте выбранный препромпт в инструкции ИИ-ассистента или в файлы проекта, если используемый сервис поддерживает такой способ работы.
3. В вводной инструкции замените `НАЗВАНИЕ_ФАЙЛА.md` на имя фактически добавленного файла.
4. В примере запроса на создание PM-ассистента указан исходный файл `AI_assist_preprompt.md`. Он не входит в этот набор: перед использованием укажите имя своего исходного препромпта и добавьте его в проект.

ИИ-материалы являются дополнительными примерами и не заменяют документацию Astra Linux. Команды и сценарии, полученные от ассистента, проверяйте на учебной виртуальной машине перед применением.

## Модуль 2. Файловая система, монтирование и дисковые устройства

[filesystem_hierarchy_and_mounting_practice.md](Mod%202/filesystem_hierarchy_and_mounting_practice.md) — подробная практика для начинающих на одной удалённой Astra Linux SE 1.7 по SSH. Иерархия каталогов, различия между диском, разделом и файловой системой, чтение lsblk, findmnt, df и fstab. Полный пример виртуальной флешки: образ 128 MiB, таблица MBR с разделом 120 MiB, loop-устройство, создание ext4, проверка принадлежности устройства образу, монтирование с ограничениями, права и запись файлов, SHA-256, режим только для чтения, диагностика занятой точки, штатное отключение и повторное подключение. Монтирование по UUID отрабатывается с отдельным учебным файлом fstab без изменения загрузочных настроек. Каждая команда сопровождается пояснениями параметров и ожидаемого результата; предусмотрены восстановление после разрыва SSH и очистка.
